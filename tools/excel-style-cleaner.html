Where all these styles come from

Every combination of font, fill, border, number format and alignment that a cell uses is stored once in the workbook as a cell format, and named styles from the Cell Styles gallery are stored the same way. Excel for Windows and Mac allows about 64,000 cell formats in one workbook (older versions allowed 4,000). Past that you get Too many different cell formats, and new formatting stops working.

Hardly anyone reaches that by formatting cells by hand. The usual cause is copying sheets between workbooks: Excel brings the source file's custom styles along with it, and over many rounds near-duplicates pile up as numbered copies such as Normal 2, Comma 3 or Currency 2 2. Templates that have been copied around for years, reports exported by accounting or ERP systems and workbooks assembled from many files can carry tens of thousands of styles that no cell uses. They make the file larger and slower to open, and they go wherever the next copied sheet goes.

Why not just delete them in Excel?

You can right-click a style in the Cell Styles gallery and choose Delete, one at a time, which isn't realistic for thousands. The common alternatives each have a catch: the macros posted on forums often stop partway on large lists and can't run in Excel for the web or where macros are blocked, the Inquire add-in's Clean Excess Cell Formatting is Windows-only and only in some Office editions, and style-removal apps for Windows don't help on a Mac. This page reads the workbook's own style list directly, works the same on any computer, and removes only what no cell uses.

FAQ

Will my formatting change?

No. A cell format is only removed when no cell, row or column refers to it, and a named style only when no remaining format is based on it. The formats that stay are renumbered and every cell reference is updated in the same pass, so each cell points at the same font, fill, border and number format as before. Conditional formatting uses a separate list and isn't touched.

I still get the error after cleaning.

Then the workbook really uses that many different formats, which usually means formatting applied cell by cell to large areas: slightly different shades, borders or fonts on every row. The report shows how many formats cells actually use. Clearing formats from ranges that don't need them (Home → Clear → Clear Formats) and applying one style to whole columns brings the number down.

What about workbooks with macros?

.xlsm files are cleaned and the macros kept. A macro that applies a style by name, such as Range("A1").Style = "Highlight 2", will fail if that style was removed because no cell used it, so check your code if it does that.

Can it clean several workbooks at once?

Yes. Add up to 20 and they're cleaned in one go, with a single ZIP download. Cleaning the source workbooks before you copy sheets between them stops the styles multiplying again.

Is my file uploaded?

No. The workbook is opened and rewritten by JavaScript in this tab using JSZip, and nothing is sent to a server. If the file is also large for other reasons, the Office file size analyzer shows which sheets, pictures and pivot caches take the space, and the Excel name conflict fixer deals with the other thing that copied sheets bring along: hidden and broken defined names.
