How it works

A .pptx, .docx or .xlsx file is a ZIP archive: each slide, picture, video, font and chart is a separate file inside it. The analyzer opens that archive in your browser with JSZip, measures every piece, and follows the file's internal links to work out where each piece is used: which slide shows a picture, which layout carries a background photo, which chart drags along a whole Excel workbook. It also reads each picture's pixel size and compares it with the size it's placed at, to tell you when a picture holds far more detail than anyone will see.

The usual reasons a deck is huge

Photos straight from a camera or phone. A 4000 × 3000 photo placed three inches wide is stored at over 1,300 pixels per inch. Projectors and screens show about 100 to 150. PowerPoint's default resolution is High fidelity, which keeps every picture at its full size, so nothing gets smaller until you run Compress Pictures or change the default under File → Options → Advanced → Image Size and Quality.

Cropping that doesn't delete anything. Cropping hides part of a picture and keeps all of it in the file, so you can undo the crop later. A photo cropped to a small detail still carries the whole frame until you run Compress Pictures with Delete cropped areas of pictures ticked.

Slides pasted from other decks. Pasting with the source formatting brings the source deck's whole slide master along, including layouts with full-screen photos that none of your slides use. After a few rounds a deck can carry several masters and dozens of layouts, and the same logo or photo saved several times under different names.

Video, audio and fonts. One embedded screen recording can outweigh everything else. WAV audio is uncompressed. An embedded font for Chinese, Japanese or Korean text can be 10 MB or more on its own unless only the characters used are embedded.

Charts and pasted tables. A chart made in Office stores a copy of the workbook behind it, and an Excel range pasted as an embedded object can carry the entire source file, every sheet included.

Why didn't Compress Pictures help?

Because the space is somewhere else. Compress Pictures only touches pictures, and only when Apply only to this picture is unticked does it touch all of them. It can't shrink video, fonts, embedded workbooks or unused layouts, and vector pictures (EMF, WMF, SVG) aren't resampled at all. Check the Where the space goes table first. If pictures are a small share, compressing them won't change much, and the report lists what to deal with instead.

FAQ

Is my presentation uploaded anywhere?

No. The file is opened and measured by JavaScript in this tab, and nothing is sent to a server, so confidential decks are fine. You can check in your browser's developer tools (Network tab) while a file is analyzed.

Does it change or compress my file?

No. It only reads the file and reports. The fixes it suggests are made in PowerPoint, Word or Excel, so you stay in control of quality, and the report says which setting does what. You can download the full list of items as a CSV to keep or share.

What resolution should pictures be?

For a deck shown on a screen or projector, 150 pixels per inch at the picture's size on the slide is plenty, and 220 ppi is safe for printing handouts. The report flags pictures over 330 ppi, the HD option in Compress Pictures, so anything it flags holds more detail than even PowerPoint's highest compression setting would keep. The ppi figure is estimated from the picture's size on the page, so treat it as a guide for pictures inside groups or with unusual scaling.

My deck has only a few slides but is 30 MB. Why?

Look at the Layouts, masters & themes and Embedded fonts rows. Templates often carry photo backgrounds on layouts nobody uses, and font embedding can add tens of megabytes with no visible change. The Slides by size table shows whether any single slide is responsible.

Does it work for Word and Excel files?

Yes. For Word it shows which pictures sit in the body or in headers and footers, their resolution, embedded fonts and objects. For Excel it lists sheets by size and flags sheets whose used range reaches far beyond the data, pivot tables that store a copy of their source data, workbooks with thousands of cell styles, and links to other workbooks. Old .ppt, .doc and .xls files aren't ZIP archives, so save them in the newer format first.

It says my file is password protected or can't be read.

A password to open encrypts the whole file, so its contents can't be measured until the password is removed (File → Info → Protect Presentation → Encrypt with Password, and clear it). A password to modify doesn't get in the way.

Can I compare several versions?

Yes. Add up to ten files at once and a comparison table at the top shows their sizes and the biggest kind of content in each, which is a quick way to find the version where the size jumped.
